# Finsight — Autonomous Financial Research Agent

Finsight is a multi-step autonomous agent that researches any publicly traded stock — US, Indian (NSE/BSE), or otherwise — and produces a structured, analyst-quality investment report with no human intervention. It also accepts a screenshot or text description of your existing holdings and returns a buy-more / hold / sell / trim call for each position.

## How it works

A ticker is researched by a [LangGraph](https://github.com/langchain-ai/langgraph) state graph of six sequential nodes, each with a distinct responsibility:

```
collect_data → analyse_news → analyse_financials → dcf_estimation → predict_verdict → write_report
```

| Node | Responsibility |
|---|---|
| **Data Collector** | Pulls live price, fundamentals, and company info via `yfinance` |
| **News & Sentiment** | Fetches recent headlines, classifies sentiment per article and overall |
| **Financial Analyst** | Identifies strengths/risks and drafts a bull case / bear case from the fundamentals |
| **DCF Estimator** | Runs a discounted cash flow model off real revenue/FCF data to estimate intrinsic value |
| **Prediction Agent** | The one place in the app that ever decides a BUY / HOLD / SELL (or BUY MORE / TRIM) call — takes every fact gathered so far and commits to a single verdict with reasoning |
| **Report Writer** | Synthesizes everything into a structured report (executive summary, highlights, bull/bear case, key metrics to watch) that narrates *around* the prediction agent's verdict rather than re-deciding it |

The **Analyze My Investments** feature reuses this same architecture: holdings are extracted from an uploaded screenshot (via Groq's vision model) or pasted text, each position is independently researched through the same data/news pipeline, the prediction agent issues a call per holding, and a final synthesis step writes the portfolio-level summary.

Every report and analysis run is persisted to SQLite with per-step timing logged, and streamed to the frontend via polling so you can watch each stage complete live.

## Features

- **Ticker research reports** — price & fundamentals, news sentiment, bull/bear analysis, DCF valuation, and a final BUY/HOLD/SELL verdict with reasoning
- **Portfolio analysis** — upload a holdings screenshot or paste your positions as text; get a per-holding recommendation plus an overall portfolio verdict, with reasoning grounded in live market data
- **Multi-currency** — works with US, Indian (NSE `.NS` / BSE `.BO`), and other international tickers; prices render in their native currency
- **Accounts & history** — email/password auth, with every report and analysis private to the account that generated it
- **Downloadable reports** — print-to-PDF export of any completed research report

---

## Tech Stack

- **Agent orchestration:** LangGraph
- **LLM:** Groq API (`qwen/qwen3.6-27b`, including vision for screenshot parsing)
- **Market data:** yfinance (price, fundamentals, news)
- **Backend:** Flask + SQLite
- **Frontend:** server-rendered HTML/CSS/vanilla JS (no framework)
- **Deployment:** Render (see `render.yaml`)

## Setup

```bash
git clone <this repo>
cd finsight
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
```

Create a `.env` file in the project root:

```
GROQ_API_KEY=your_groq_api_key
SECRET_KEY=any_random_string
```

Run it:

```bash
python app.py
```

Then open `http://localhost:5000`, sign up, and generate a report.

---

## Deployment

The included `render.yaml` deploys Finsight as a single Render web service (`gunicorn app:app`). `SECRET_KEY` is auto-generated by Render; `GROQ_API_KEY` must be set manually in the service's environment settings.

Note: on Render's free tier the filesystem is ephemeral, so SQLite data (accounts, report history) resets on each redeploy. For persistence across deploys, mount a persistent disk at the app's working directory.
